## 1. Project

OCaml EDSL that compiles Gather-Apply-Scatter graph algorithms (SSSP, PageRank, BFS, WCC, ...) to NVIDIA PTX. Static CSR graphs. Team of 3 (Raagam Parmar, M. Sreenath Karthick, M. Murali Karthick), GPU Programming course. Repo: https://github.com/Raagam-Parmar/gas-dsl. **Target arch is `sm_75`** (not sm_80/A30; `pipeline/scripts/config.sh` still says sm_80 — stale).

## 2. Pipeline / architecture

```
Edsl -> GraphIR.Ast.algorithm
     -> GraphIR.Translate.translate   : algorithm -> LowerIR.Ast.kernel list
     -> LowerIR.Translate.translate ?(target="sm_75") : -> Ptx.Ast.program
     -> Ptx.Printer.to_string
```
- Modules (qualified subdirs, library `gas_dsl`, public name `gas-dsl`): `Gas_dsl.{Edsl,GraphIR,LowerIR,Ptx,Examples}`.
- Kernels: edge-parallel `<name>_scatter` + optional vertex-parallel `<name>_apply`. Augmented CSR (`src_indices`), SoA layout.
- Scatter params: `<fields>_ptr..., [weight_ptr], row_offsets_ptr, src_indices_ptr, dst_indices_ptr, num_edges, num_vertices`. Apply: field ptrs + `num_vertices`. Host `args[]` must match exactly.
- Float min/max reductions use an `atom.cas.b32` loop (`LowerIR.Helper.expand_cas_loop`); ints use native `atom.min/max`, floats `atom.add.f32`.
- EDSL: phantom-typed `'a expr`, `Vertex.*`/`Edge.*` fields, `scatter ~target ~reduce (fun ~src ~dst ~edge -> ...)`, `apply ~dest (fun ~self -> ...)`, `algorithm`. Edsl only depends on GraphIR.
- `lib/examples/examples.ml`: sssp_u32, sssp_f32, pagerank, bfs, wcc, in_degree, max_influence, `all`.
- `pipeline/ptx/*.ptx` (generated), `pipeline/host/*_host.cu` (CUDA Driver API harnesses with CPU golden check), `pipeline/scripts/{config.sh,run.sh,submit.template.sh}` (HPC upload/compile/sbatch; cluster reachable only on institute network).
